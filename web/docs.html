API Reference

Send personalized ringless voicemail drops programmatically. REST, JSON in and out.

Authentication

Create an API key in Settings → Developer. Send it on every request as an X-API-Key header. Keys are scoped to your workspace.

curl https://api.colddrops.app/api/campaigns \
    -H "X-API-Key: cd_live_xxxxxxxxxxxx"
Base URL is your deployment's host. Keys carry your plan's monthly drop limit — the same metering as the app.

Campaigns

POST /api/campaigns

Create a campaign. script supports {{first_name}}, {{company}}, {{title}}, {{city}}. Add variants for A/B testing.

{
  "name": "Q3 brokers",
  "script": "Hey {{first_name}}, it's Alex — quick one.",
  "variants": ["Hi {{first_name}}, promise I'll be brief."]
}
GET /api/campaigns

List your campaigns with contact and delivered counts.

GET /api/campaigns/{id}

Campaign detail: contacts and drop stats.

GET /api/campaigns/{id}/analytics

Per-variant sent / delivered / callbacks, callback rate, and the winning variant.

Contacts

POST /api/campaigns/{id}/contacts
FieldNotes
first_name, last_nameused for personalization
company, title, country, cityoptional merge fields
mobilerequired to drop — E.164 preferred
email, linkedin_urloptional
{ "contacts": [ { "first_name": "Kevin", "company": "Acme", "mobile": "+14155550100" } ] }

Send

POST /api/campaigns/{id}/send

Queue drops for all pending contacts. Runs the pipeline: script merge → voice render → delivery. Respects your plan cap and DNC list. Returns queued / skipped counts.

POST /api/campaigns/{id}/schedule

Schedule a send: { "at": 1735689600 } (unix seconds). Fires automatically when due.

Compliance

POST /api/suppressions

Add a number to your do-not-contact list: { "phone": "+14155550100" }. Suppressed numbers are skipped on every send, permanently.

Results

GET /api/callbacks

Prospects who called back.

GET /api/dashboard

Workspace totals: drops sent, delivered, callbacks, campaigns.

GET /api/campaigns/{id}/contacts.csv

Export a campaign's contacts as CSV.

Webhooks

Point your telephony provider's inbound events at /api/webhooks/telnyx; Colddrops matches inbound callers to contacts and logs callbacks automatically.

Every write is metered against your plan and enforced server-side, exactly like the app. Use the API responsibly and within the law — see the DNC & Acceptable Use policy.
