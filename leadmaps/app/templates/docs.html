API reference

Submit a search, poll until it is done, take the rows. Available on Starter and above.

Authentication

Send your key in the X-API-Key header. Create keys in the dashboard.

curl {{ public_url }}/api/v1/usage -H "X-API-Key: lm_live_..."

POST /api/v1/searches

Queue a search. Responds 202 with the job id.

curl -X POST {{ public_url }}/api/v1/searches \
  -H "X-API-Key: lm_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "keyword": "dentists in Manchester",
    "lang": "en",
    "max_depth": 3,
    "extract_emails": false
  }'
FieldTypeNotes
keywordstringRequired. What to search for.
langstringTwo-letter language code. Default en.
max_depthintPages to paginate, ~20 businesses each. Capped by your plan.
extract_emailsboolCrawl each business website for emails. Growth and above.
geo_coordinatesstring"lat,lon" to centre the search.
zoomint1–21. Map zoom when using coordinates.
radiusfloatSearch radius in kilometres.

GET /api/v1/searches/{id}

Poll for status and results. status is one of queued, running, completed, failed, cancelled.

{
  "id": "0f7c…",
  "status": "completed",
  "keyword": "dentists in Manchester",
  "result_count": 60,
  "results": [
    {
      "title": "Northern Dental Care",
      "category": "Dentist",
      "address": "12 High St, Manchester",
      "phone": "+44 161 555 0198",
      "web_site": "https://example.com",
      "review_rating": 4.7,
      "review_count": 214,
      "latitude": 53.4808,
      "longtitude": -2.2426,
      "emails": []
    }
  ]
}

Pass ?include_results=false to omit the rows.

GET /api/v1/searches/{id}/results.csv

The same rows as a CSV download.

GET /api/v1/searches

List your searches, newest first. Supports limit (max 100) and offset.

GET /api/v1/usage

Your plan, allowance and leads consumed this period.

{"plan": "growth", "period": "2026-08", "included": 25000, "used": 1840, "remaining": 23160}

Errors

CodeMeaning
401Missing, invalid or revoked API key.
402Monthly lead allowance exhausted, or payment failed.
403Your plan does not include the requested feature.
404No such search on your account.
422The request body did not validate.
429Too many searches running at once.
503The scraping engine is temporarily unavailable.

An interactive OpenAPI explorer is at /api/docs.
